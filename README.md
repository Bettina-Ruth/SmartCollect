# SmartCollect

An AI-powered loan recovery and risk prediction platform that helps financial institutions identify high-risk borrowers, prioritize recovery actions, and streamline collection workflows.

## Features

* Borrower management dashboard
* Loan and EMI tracking
* Risk categorization (Low, Medium, High)
* Recovery recommendation system
* Borrower details page
* Analytics dashboard
* RESTful backend APIs
* PostgreSQL database integration using Prisma (in progress)
* AI-powered loan default prediction (planned)
* Authentication and authorization (planned)
